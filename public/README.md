# Public Directory

This directory contains the built documentation for GitHub Pages deployment.

The contents are automatically generated by the GitHub Actions workflow and should not be edited manually.

## Structure

- `index.html` - Landing page for the documentation
- `html/` - Sphinx-generated documentation
- Other static assets for the documentation
